# Нижегородское училище-интернат

Модернизированная демонстрационная версия публичного сайта [npu-nn.ru](https://npu-nn.ru/).

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Сведения взяты с официальных страниц и из отчёта о самообследовании по состоянию на 1 апреля 2025 года. Форма обратной связи сохраняет черновик только в браузере и не отправляет его в училище. ФИО директора не указано: открытые источники расходятся.
